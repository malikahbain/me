Ottawa Transit Tracker — Privacy Policy

Effective date: October 5, 2026. Describes the current private Devvit playtest.

Project identity and contact

Ottawa Transit Tracker is an independent project maintained by Malikah Bain. It is not affiliated with or endorsed by OC Transpo or the City of Ottawa. For privacy questions, contact malikahbain@gmail.com and identify Ottawa Transit Tracker in the subject. Please do not send credentials or precise travel histories.

Public transit information

The app processes static GTFS schedules, stops, routes, and geometry, and GTFS-Realtime VehiclePositions and TripUpdates supplied through City of Ottawa / OC Transpo public transit data services. These include operational vehicle/trip/stop identifiers, bus coordinates and timestamps, predictions, explicit service cancellations, and source references. A bus coordinate is an operational transit observation, not a request for your location.

The current collector fetches whole-network feeds on the server and matches a six-route static test index for display. It sends no Reddit posts, comments, usernames, votes, or rider-selected stops to OC Transpo. City of Ottawa traffic/open-data context and public weather data such as Environment Canada may be implemented later; these are not currently connected services.

Your use of the app

You manually choose a route, direction, and stop. The current app does not request precise device location or build a stored personal travel history. Language and display preferences use local browser storage. Switching between inline and expanded Devvit views can also save the current route/direction/stop selection locally for a brief handoff. The app stops using that handoff after one minute; a record can remain on the device until it is removed, overwritten, or browser storage is cleared. These preferences and selections are not written to the transit database.

Reddit/Devvit supplies runtime context needed to run the app. Moderator-only diagnostics use the moderator's Reddit username to check authorization. The current transit collector does not persist that username, Reddit user content, or individual rider selections. Collector metadata includes the installation's subreddit identifier; this is operational app context, not an individual rider profile.

Storage and retention

Devvit Redis stores current vehicle observations and predictions, feed health, short-lived locks, collection controls, current post identifiers, and a bounded recent collector-run history. Hot feed chunks expire after roughly three to four minutes; operational controls and bounded metadata can remain longer.

Supabase/Postgres stores the private validation tables for vehicle positions, trip-update predictions, collector runs, and feed health. Migration 002 prunes observations older than 15 minutes and collector-run metadata older than seven days during collection. If collection is paused, cleanup does not run, so elapsed wall-clock time alone does not guarantee immediate deletion. Feed-health rows and provider-managed backups may remain longer according to provider configuration. The app's validation tables have a storage budget. This is a bounded integration test, not the final long-term research archive.

Providers and network metadata

Reddit/Devvit hosts the app and processes its platform interactions. Supabase provides the private Postgres storage. City of Ottawa / OC Transpo supplies transit data. GitHub Pages is the intended host for project policy pages; GitHub Pages/Releases may host research material later. These providers have their own privacy policies and may process network metadata, IP addresses, cookies, account information, security logs, or backups when you use their services. This policy does not claim that such metadata never exists or control all provider retention.

The app uses server-side API credentials to request transit data and write validation observations. Supabase receives public operational transit observations, timestamps, source references, and installation metadata. The current app does not send individual rider selections or Reddit user content to Supabase. The app does not sell personal user data.

Public research releases

Validated operational transit datasets or aggregate research findings may be published later with provenance, quality information, and applicable source licences. No public raw dataset release or validated historical reliability report is currently claimed. Individual rider selections and personal travel histories are not intended research outputs.

Security and accuracy

The project uses reasonable safeguards, including encrypted server settings, fixed permitted hosts, a server-only ingestion function, private database tables with access restrictions, and logs that omit credentials and response bodies. No system can guarantee perfect security. Realtime data can be delayed or incomplete; predictions remain projected, and derived stop events may be inferred. This app is informational and research-oriented, without a guarantee of exact arrivals.

Questions and updates

Contact the project for questions about its handling of data. Browser preferences can be removed using your browser's site-storage controls. For platform account or provider-held network data, use the relevant provider's controls. This policy may be updated as features and retention change; the effective date will identify the current version.
